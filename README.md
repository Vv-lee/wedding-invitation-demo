## 当前体验

浅粉与香槟金的手机端请柬，配有缎带、并蒂双 Y 标识、英文花体与中文姓名书法字。电脑上以居中的手机阅读宽度展示。

- **开场短片**：点播观看带原声和字幕的短片。18 秒动态画面后保留 1 秒定格，接完“的朋友啊”的原声结尾；共 19 秒，也可随时跳过。
- **拆开邀请**：短片结束后进入蜡封封面。拆信后可停留阅读，再点“走进我们的婚礼”进入正文。
- **配乐与标识**：拆信时播放 Love Story，可暂停并保留播放进度；短片原声与配乐不会叠加。点击双 Y 标识可放大并阅读设计灵感。
- **照片系列**：日常、订婚、领证，以及婚纱照的园林、唐服、大婚肖像、油画、城堡。玻璃心形在框内漂移，点击打开相册；看过的分类留在框内，以金色小勾和“已看过”区分，可再次查看。
- **婚礼日程**：查看时间、倒计时与阳历／农历日期，并下载婚礼日历。
- **赴约导航**：复制酒店地址，或通过腾讯地图、高德地图前往。
- **专属邀请**：填写称呼，生成并下载专属 PNG 邀请卡。称呼与查看记录保存在当前浏览器本地，没有出席回执提交功能。

新人照片暂留占位，等待补充。切到后台时，正在播放的短片和配乐会暂停。
